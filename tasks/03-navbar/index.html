Responsive navigation bar

Resize the window past 860px to see the bar swap between its two modes. Everything below exists only to give the sticky header something to scroll over.

What this navbar does

  • Sticks to the top with a blurred, translucent background.
  • Collapses into a hamburger drawer below 860px.
  • Animates the hamburger into a close (X) icon when open.
  • Turns the desktop dropdown into an inline accordion on mobile.
  • Closes on Escape, on backdrop click, or on outside click.
  • Traps nothing and hijacks nothing — plain links, fully keyboard operable.

Accessibility notes

  • aria-expanded on both toggles reflects the real open state.
  • aria-controls points each button at the element it opens.
  • The dropdown trigger is a <button>, not a link — it goes nowhere.
  • A skip link (press Tab on load) jumps straight to the content.
  • Focus returns to the hamburger when the drawer closes with Escape.

Scroll filler

The header stays put while this scrolls beneath it. On mobile the drawer also locks page scrolling so the background does not move behind it.

Media queries do the layout work; JavaScript only manages open/closed state and the matching ARIA attributes.
